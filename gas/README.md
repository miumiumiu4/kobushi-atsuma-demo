# Google 連携のつなぎ方（約 10 分）

1. Google ドライブで新しいスプレッドシートを作る（名前の例：こぶしの湯 サイト受付）
2. メニュー「拡張機能」→「Apps Script」
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの `Code.gs` を貼り付けて保存
4. 上の関数の選択で `setup` を選び「実行」→ 許可の画面で、自分のアカウントを選んで許可
   → シート「受付」「お知らせ」ができる
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 出てきた「ウェブアプリの URL」（https://script.google.com/macros/s/…/exec）をコピー
7. サイトの `config.js` の `GAS_URL: ""` の中に貼って、公開しなおす

## 使い方
- 受付：フォームが届くと「受付」シートに 1 行増え、メールが届く。「状態」列で 未対応→連絡済→確定 を管理
- お知らせ：「お知らせ」シートに 日付・種類・タイトル を書き、「表示」列に ○ を入れるとトップに出る（新しい順に 5 件）
- 通知先を変えたいとき：`Code.gs` の `NOTIFY_TO` にメールアドレスを書いて、デプロイを「新しいバージョン」で更新
