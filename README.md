# こぶしの湯あつま — Web サイトの作り直し案（制作サンプル・非公式）

元のサイト https://www.kobushi-atsuma.com/ の内容を、見やすく・スマホで使いやすく作り直した見本です。

**デザイン（2026-10-21 第2版）**：大手リゾートの公式サイトのような、白と墨・広い余白・大きな写真・日程と人数で探す「空室検索」が主役の作り。ほかの会社の名前・ロゴ・写真・文章は使っていません。

**予約のわかりやすさ**：トップと全ページから「空室検索」へ。カレンダーで日程、＋−で人数を選ぶと、泊まれるお部屋・料金（ムービングハウスは自動計算）・予約の方法（ネット予約／問い合わせ／電話）が1画面に並ぶ（reserve.html）。宴会は日付（7日後から）・コース・人数を選んで申し込みへ。
施設の公式サイトではありません（全ページの上に「制作サンプル（非公式）」と表示し、検索エンジンには載せない設定）。

## 元のサイトの機能と、この版での扱い

| 元のサイト | この版 |
|---|---|
| 電話・FAX・住所（全ページ上部） | ヘッダーに電話。スマホは画面下に「電話・宿泊予約・アクセス」を常に表示 |
| メニュー（7 ページ） | 同じ 7 ページ＋アクセス・安心安全。スマホは開閉式 |
| スライド（ようこそ・グルメ・お風呂・ムービングハウス・宿泊） | 同じ 5 枚。ボタンで切り替え、動きを減らす設定の人には自動で動かさない |
| 宿泊予約（外部の予約システム）・予約の確認/キャンセル | 同じ予約先へのボタンを全ページに |
| YouTube 紹介動画 | 押したときだけ読み込む（ページが速い） |
| おすすめ情報 4 件（パークゴルフ・合宿・グルメ・EV 充電器） | カードで表示 |
| お知らせ | **Google スプレッドシートから自動表示**（スタッフがシートに書くだけで更新） |
| Facebook | フッターにリンク |
| Google 翻訳（英・韓・中） | 「Language」ボタンで同じ翻訳 |
| 厚真町の関連リンク 7 件 | フッターとアクセスページ |
| お風呂（6 種・備品・日帰り時間・料金・回数券・販売品） | 全部＋「いま営業中か」表示＋人数で入浴料の合計 |
| レストラン（全 42 品と価格） | 全部＋分類タブ＋検索＋豚丼の販売時間の表示 |
| 本館宿泊（和室・洋室・研修室・時間・料金は電話） | 全部＋空室の問い合わせフォーム |
| ムービングハウス（説明・定員・設備・備品・料金表） | 全部＋**人数と泊数で料金を自動計算** |
| 宴会・法要（4 コース・注意・送迎無料） | 全部＋**ネットで申し込み**（7 日前・名入れは 14 日前のチェック、料理の目安金額、Google カレンダーに仮登録） |
| お問い合わせ（電話のみ） | 電話＋**フォーム**（一般・空室・ムービングハウス・合宿） |
| コロナ対策のページ | 「安心・安全への取り組み」として同じ内容 |
| 加工体験（リンク先が 404） | 元のページが無いため未掲載 |

## Google 連携
- フォーム → Google スプレッドシートに記録＋施設へメール通知＋お客さまへ自動返信（`gas/Code.gs`）
- お知らせ → スプレッドシートの「お知らせ」シートから表示
- 地図・道順 → Google マップ
- 翻訳 → Google 翻訳
- 宴会の申し込み後 → Google カレンダーに仮で入れるボタン

つなぎ方は [gas/README.md](gas/README.md)。つなぐまではフォームは「デモ表示」で、送信はされません。

## 写真
元のサイトの写真は使っていません（色と模様の仮の絵）。本番では施設の写真に差し替えます。

## 更新のしかた
`_pages/` のページを直して `python3 build.py` を実行すると、公開用の HTML ができます。
料金・メニューは `assets/data.js`、つなぎ先は `config.js`。
